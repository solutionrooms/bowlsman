# Scoring

The Scoring system in Bowlsman allows you to record, track, and analyze bowling scores for competitions and practice sessions. This guide explains how to use the scoring features effectively.

## Scoring Basics

### Understanding Scoring

Bowlsman's scoring system is designed to be flexible and accommodate different scoring methods used in various bowling formats:

- Each competition can define its own scoring rules
- Scores can be entered per game or as a series total
- The system automatically calculates standings based on the competition rules

## Entering Scores in Bowlsman

### Live Scoring

To score a game in real-time:

1. Navigate to the competition or practice session
2. Select "Live Scoring"
3. Choose the lane and bowlers
4. Enter scores as the game progresses
5. The system automatically calculates running totals
6. Submit the final scores

### Quick Score Entry

For rapid entry of just the total scores:

1. Select "Quick Score Entry"
2. Enter the total score for each game
3. Submit the scores

## Scoring Features

### Automatic Calculations

Bowlsman automatically:

- Calculates running totals
- Validates entries for correctness
- Computes final scores and series totals

### Score Verification

To verify scores:

1. Review the complete scoresheet
2. Check for any unusual patterns or errors
3. Compare with physical scoresheets if available
4. Have a second person verify if required
5. Mark scores as "Verified" when confirmed

## Score Analysis

### Individual Statistics

View detailed statistics for any bowler:

1. Navigate to the bowler's profile
2. Select "Statistics" or "Score History"
3. View metrics such as:
   - Average score
   - High game
   - Performance trends

### Comparative Analysis

Compare scores across:

- Different competitions
- Time periods
- Venues
- Equipment used

### Performance Trends

Track improvement over time:

1. Go to "Performance Analysis"
2. Select the date range
3. View trend charts and graphs
4. Identify patterns and areas for improvement

## Troubleshooting Scoring Issues

If you encounter problems with scoring:

1. **Cannot Submit Scores**: Ensure all required fields are completed
2. **Scores Not Appearing in Results**: Check that scores were properly submitted and approved

For additional help with specific scoring scenarios, please contact your league secretary or competition organizer.
