# Messaging

The Messaging system in Bowlsman allows you to communicate with other users, teams, and club administrators. This guide explains how to use the messaging features effectively.

## Messaging Overview

The Bowlsman messaging system provides:

- Direct messages between individual users
- Group conversations for teams and clubs
- Notifications about system events
- File and image sharing capabilities

## Accessing Messages

To access your messages:

1. Click on the "Chat" or "Messaging" option in the main navigation menu
2. View your message inbox showing all conversations
3. See unread message count indicators
4. Access archived conversations if needed

## Starting a New Conversation

### Direct Messages

To send a direct message to another user:

1. Go to the Messaging section
2. Click "New Message" or the compose icon
3. Search for and select the recipient
4. Type your message in the text field
5. Add attachments if needed (photos, files)
6. Click "Send"

### Group Messages

To start a group conversation:

1. Go to the Messaging section
2. Click "New Group"
3. Search for and select multiple recipients
4. Give the group a name (optional)
5. Type your initial message
6. Click "Send"

## Managing Conversations

### Reading and Replying

To read and reply to messages:

1. Select a conversation from your inbox
2. Read the message thread
3. Type your reply in the text field at the bottom
4. Add attachments if needed
5. Click "Send"

### Message Actions

For each message, you can:

- Reply directly
- Forward to another user
- Copy the message text
- Delete the message (for messages you sent)
- Report inappropriate content

### Conversation Management

For entire conversations, you can:

- Mute notifications
- Archive the conversation
- Mark all messages as read
- Leave a group conversation
- Delete the conversation history

## Messaging Features

### Attachments

To share files and images:

1. Click the attachment icon in the message composer
2. Select the file from your device
3. Add an optional description
4. Send the message with the attachment

Supported file types include:
- Images (JPG, PNG, GIF)
- Documents (PDF, DOC, DOCX)
- Spreadsheets (XLS, XLSX)
- Text files (TXT)

### Notifications

Messaging notifications:

- Appear in the navigation bar
- Show a count of unread messages
- May send email notifications (if enabled in settings)
- Can be customized in your notification preferences

## Team and Club Messaging

### Team Conversations

Team conversations automatically include:

- All team members
- Team captain(s)
- Team coach (if assigned)

Team captains can:
- Add or remove members
- Pin important messages
- Send announcements to the team

## Messaging Etiquette

For effective communication:

- Keep messages clear and concise
- Use appropriate and professional language
- Respect others' privacy and time
- Avoid sending too many messages in a short period
- Use group messages only when necessary

## Privacy and Security

The Bowlsman messaging system:

- Encrypts message content
- Restricts access to authorized users only
- Allows you to block unwanted contacts
- Provides reporting tools for inappropriate content
- Retains message history according to the privacy policy

## Troubleshooting Messaging Issues

If you encounter problems with messaging:

1. **Messages Not Sending**: Check your internet connection
2. **Missing Conversations**: Verify they haven't been archived
3. **Not Receiving Notifications**: Check your notification settings
4. **Cannot Find User**: Confirm the spelling of their username
5. **Attachments Not Uploading**: Ensure the file is under the size limit and in a supported format

For additional help with specific messaging issues, please contact support.
